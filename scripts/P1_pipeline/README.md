# P1 Pipeline Scripts

Purpose: build the main reproducible empirical pipeline after P0 feasibility is established.

This stage covers:

- canonical Polymarket event cells;
- Polymarket history panels;
- Deribit OHLC and risk-neutral-distribution panels;
- Track A distribution-divergence diagnostics;
- Track B survival and lead-lag panels;
- paper-facing tables and figures used by the frozen P1 result set.

Primary outputs stay in `data/processed/`, `paper/tables/`, and `paper/figures/`.
