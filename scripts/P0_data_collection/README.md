# P0 Data Collection Scripts

Purpose: collect baseline market data, test public API feasibility, and build initial inventories.

Typical outputs:

- `data/raw/polymarket/`
- `data/raw/deribit/`
- `data/processed/polymarket/`
- `data/processed/deribit/`
- `data/processed/polymarket_spike/`
- `data/processed/deribit_spike/`

These scripts are allowed to call external market APIs. Run them deliberately and record the data snapshot date in metadata outputs.
