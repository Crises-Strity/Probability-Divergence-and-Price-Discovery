# Docs Directory

This directory holds project planning, methodology decisions, and implementation notes.

```text
docs/roadmap/
  High-level project roadmap and topic outline.

docs/specs/
  Pipeline and output specifications.

docs/decision_logs/
  Empirical freeze notes and decision logs.

docs/superpowers/
  Agent-generated design and implementation plans for repo maintenance work.
```

Historical documents may still mention old script paths. Treat current executable paths in `scripts/P0_data_collection`, `scripts/P1_pipeline`, and `scripts/P2_diagnostics` as the active layout.
